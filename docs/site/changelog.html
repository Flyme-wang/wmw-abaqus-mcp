CHANGELOG

6.0.0 — 2026-10-23（源码候选版，未正式发行）

本次更新

  • 桥接端统一控制每个 CAE 会话的单个在途操作；忙碌请求明确返回，避免继续积压。
  • GUI 回调移除循环等待与连续批量执行，派发前登记活动状态，结果以原子文件回执收集。
  • 新增请求状态追踪与查询；未派发请求过期不执行，已派发超时保持占位，不自动重放或终止计算。
  • MCP 工具支持稳定请求编号；超时后查询原请求结果，不再把网络超时视为脚本已停止。
  • 不兼容变化：submit_job 仅提交并立即返回；完成状态改由独立监测查询，因此升级主版本。
  • 同步安装元数据与本地中英文说明；实际验证范围见 验证记录。

部署说明：本次按用户授权同步 GitHub 源码，未创建正式 Release。离线测试不等于真实 CAE 验收；本次不热改在用源码、不重启 CAE、不修改模型或求解参数。

5.2.0 — 2026-10-15

本次更新

  • 将正在使用的 v5.2.0 多端口桥接源码同步为独立公开项目 wmw-abaqus-mcp。
  • 保留菜单自动分配端口、显式端口选择、会话发现、活动切换及 session_id 路由。
  • 同步包元数据为 5.2.0，统一项目、MCP server 和 GUI 菜单显示名；环境变量和工具 API 保持兼容。
  • 补全多窗口连接、默认资源适用范围、隔离验证和本地字体排版说明。

版本说明：5.2.0 是原本在用的插件版本，多端口功能已存在。原目录包元数据仍为 5.1.0，本次在发布副本统一版本；原始源码和正在运行的会话未被改写。

实际验证范围见验证记录，隔离路由检查与真实 CAE/求解验证分别说明。
